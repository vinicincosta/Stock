# Stock
Project stock (Delphi)

## Sobre o projeto
Projeto desenvolvido em Delphi com o objetivo de gerenciar produtos e movimentações de estoque.

## Funcionalidades
- Cadastro de produtos.
- Cadastro de movimentações de estoque.
- Consulta de movimentações.
- Interface gráfica desenvolvida em Delphi.

## Tecnologias utilizadas
- Delphi
- Object Pascal
- Arquivos DFM para as interfaces gráficas.

## Estrutura do projeto
- `Estoque_teste.dpr`: arquivo principal do projeto.
- `UnitPrincipal.pas`: tela principal.
- `UnitCadProdutos.pas`: cadastro de produtos.
- `UnitCadMovimentacoes.pas`: cadastro de movimentações.
- `UnitConsMovimentacoes.pas`: consulta de movimentações.
- `UnitDm.pas`: módulo de dados.
